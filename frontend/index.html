طريقة الضبط حسب نوع ماكينة التصوير الخاصة بك:

ماكينات ريكو (Ricoh Aficio):
  1. اضغط زر Scanner على لوحة الماكينة.
  2. اختر Folder ثم Manual Entry.
  3. اختر SMB واكتب مسار المجلد واسم المستخدم.
  4. حدد الدقة 200 أو 300 DPI وصيغة PDF متعدد الصفحات.
ماكينات كانون (Canon imageRUNNER):
  1. اضغط Send أو Scan and Send.
  2. اختر Address Book ثم إضافة File (SMB).
  3. أدخل اسم الكمبيوتر والمجلد المشترك.
ماكينات زيروكس وشارب وكونيكا (Xerox / Sharp / Konica):
  1. ادخل على صفحة إدارة الماكينة عبر المتصفح (Web Image Monitor).
  2. انتقل إلى Address Book ثم أضف وجهة مسح من نوع SMB / Network Folder.
